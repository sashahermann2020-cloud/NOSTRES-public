# Security policy

## Reporting a vulnerability

If you find a vulnerability, a way to access data that should not be accessible, or a key or secret in this repository, write to <alexandra.hermann@nostres.world>. Please do not open a public issue for it.

Include what you found, where (file, URL or route) and how to reproduce it. You will get a reply as soon as possible, usually within a few days.

## Scope

- The application code in this repository and the website <https://nostres.world>.
- The mirror process: this repository is a snapshot of the private repository and is scanned for secrets before each update. If something private still reached this repository, report it in the same way.

## What NOSTRES stores

Answers and progress stay in the user's browser. The server stores only technical events of route use and anonymous feedback; NOSTRES does not ask for names, addresses or document numbers and does not accept document uploads. Details: <https://nostres.world/privacy>.
